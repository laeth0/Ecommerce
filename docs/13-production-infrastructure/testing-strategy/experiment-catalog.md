# Infrastructure Experiment Catalog

**Status:** future manual/operational evidence designs. This task creates no automated tests, fixtures, scripts, generator, fault platform, cluster or credentials.

## Common experiment contract

Use an approved isolated local target, actual versions/data/resource/source/profile, exact operator/reviewer authority and protected stop/reversal. Preserve current one-executor/account and original history.

Simulator/transport experiments remain isolated Development with provider egress fenced. Genuine provider probes use original StripeSandbox/test-method source, ≤100 affected objects, ≤0.5 new payments/sec/0.1 refunds/sec and all calls≤5/sec/burst2/concurrency2.

Abort on lost authority/identity/history, live account, second executor, stock/money violation, secret exposure or exceeded process/pool/disk gate. Stop new unsafe work while retaining original accepted evidence/uncertainty. Reversal removes the injected condition, not a hold, receipt or provider effect.

## Evidence format

Each branch records hypothesis, actual target/version/data/source/resources, original release/command/source/owner references, operator/time, action/reversal, complete measurements, invariants and safe cleanup/reopen. Planned experiments remain Not run. The future automated-test boundary follows the user's explicit instruction.
